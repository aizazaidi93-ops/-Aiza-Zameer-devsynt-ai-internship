This folder contains a static HTML page summarizing what I learned this week about LangChain and LangGraph — the foundation for the upcoming orchestrator-agent project.

# How to Run:
Open "index.html" in any web browser (double-click the file, or right-click → Open With → your browser).

# What I Learned
This week I learned the difference between calling an LLM directly and using LangChain's reusable building blocks like prompt templates and chains. I also learned how LangGraph turns a fixed sequence into a decision-making system using nodes, edges, and state — which is why the upcoming orchestrator agent project needs it.
