01

What is LangChain?

LangChain provides reusable building blocks for working with Large Language Models. Instead of writing every API interaction from scratch, developers can use components such as prompt templates, chains, and LLM wrappers.

Prompt Template
→
LLM
→
Output

Chain vs Raw API Call

A raw API call usually sends a prompt directly to an LLM and receives raw text. A LangChain chain connects reusable components into a repeatable process.

02

Prompt Templates & Output Parsers

Prompt Template

A prompt template is a reusable prompt containing variables. The same template can be used with different values.

PromptTemplate(
  template="Explain {topic} simply."
)

Output Parser

An output parser helps turn an LLM's free-form response into a predictable structure that application code can work with. JSON is one common structured format.

Plain Output

Free-flowing text

Structured Output

Specific fields and predictable format

03

Memory & Tool Calling

🧠 Memory

Memory means keeping track of previous conversation messages so an application can use earlier context in later interactions.

🛠️ Tool Calling

Tool-calling allows an LLM to choose functions such as a calculator, search function, or database lookup when additional information or action is needed.

04

What is LangGraph?

LangGraph is used to build decision-making systems as graphs. Unlike a simple fixed sequence, an agent can decide what to do next, choose between paths, or repeat a step.

Chain

Fixed sequence of steps.

VS

Agent

Can decide what to do next.

05

Core LangGraph Concepts

Node

A step or unit of work in the graph.

Edge

A connection showing what happens next.

State

Data that is passed along and updated through the graph.

Conditional Edge

A decision point that determines the next path.

Orchestrator Agents

An orchestrator agent receives a task, determines what needs to happen, and routes the task to the appropriate specialized agent. It acts more like a manager than the worker performing every individual task.
